Getting started

  1. Install Prime Kids: Parent Helper on the parent's phone and create an account.
  2. Install Prime Kids on the child's phone.
  3. In the parent app, add a child and tap Pair device to get a pairing code.
  4. Enter the code in the child app and grant the requested permissions (location, notifications, and on iOS Screen Time authorisation).

Frequently asked questions

  • The child's location is not updating. Make sure Location is set to Always for Prime Kids on the child's device and that the device is online.
  • I lost my pairing code. Generate a new one from the parent app; old codes expire after 60 minutes.
  • How do I unpair a device? In the parent app open the child → Devices → Unpair. The child app returns to the pairing screen.
  • How do I delete my account? Parent app → Settings → Delete account. Deletion completes after a 30-day grace period; you can cancel within that time.
  • Which features differ between Android and iOS? On iOS, web filtering applies to Safari only and app limits are enforced through Apple's Screen Time framework. Remote lock is available as "pause device". See the in-app help for details.
