# Prime Kids — App Privacy (Nutrition Labels)

Apple requires developers to disclose data collection practices. Below are the
privacy nutrition label declarations for the Prime Kids child app.

Reference: https://developer.apple.com/app-store/app-privacy-details/

---

## Data Linked to User

### 1. Location — Precise Location
- **Purpose:** App Functionality
- **Linked to User:** Yes
- **Used for Tracking:** No
- **Details:** GPS coordinates are collected to show the child's location to
  the paired parent/guardian. Location is tracked in the background to enable
  geofence alerts and SOS emergency features.

### 2. Identifiers — Device ID
- **Purpose:** App Functionality
- **Linked to User:** Yes
- **Used for Tracking:** No
- **Details:** A unique device identifier is generated during pairing to
  associate the child's device with the parent's account. This identifier is
  used solely for device authentication and is not shared with third parties.

### 3. Usage Data — Product Interaction
- **Purpose:** App Functionality
- **Linked to User:** Yes
- **Used for Tracking:** No
- **Details:** App usage duration and screen time data are collected so the
  parent can monitor and manage the child's device habits. Data includes which
  apps are used and for how long.

### 4. Browsing History
- **Purpose:** App Functionality
- **Linked to User:** Yes
- **Used for Tracking:** No
- **Details:** URLs visited in Safari are logged to allow the parent to review
  browsing activity and enforce web content filters. This data is only
  accessible to the paired parent/guardian.

### 5. Diagnostics — Performance Data
- **Purpose:** App Functionality
- **Linked to User:** No
- **Used for Tracking:** No
- **Details:** Battery level and online/offline device status are reported to
  the parent. Crash logs may be collected to improve app stability.

---

## Data NOT Collected
- Financial Info
- Contact Info (the child does not enter any personal information)
- Contacts
- Health & Fitness
- Sensitive Info
- User Content (photos, videos, etc.)
- Audio Data
- Search History
- Purchases
- Other Data

---

## App Tracking Transparency
This app does NOT track users across other companies' apps or websites.
ATT prompt is not required.
