# Reviewer video — Prime Kids: Child (60–120 s screen recording)

Why: Family Controls apps get fewer review round-trips when the reviewer can *see* authorisation and shielding. Record on the child iPhone (Control Center → Screen Recording; enable microphone if you want to narrate — optional). Attach the .mp4/.mov in App Store Connect → Prime Kids: Child → 1.0 → App Review Information → Attachment (max 500 MB), or upload to a private link and paste the URL in Notes.

Before recording: parent app installed & signed in as review@parenthelper.com on another phone (or the same phone — switching apps is fine); child app freshly installed / unpaired.

## Shot list (keep it linear, no cuts needed)
1. **Pairing (10 s)** — open Prime Kids: Child, type `PRIME888`, tap Pair → "Device Protected".
2. **Onboarding (25 s)** — Allow notifications → Allow location → choose **Always Allow** (or While Using) → **Authorise Screen Time**: show the system sheet, approve with passcode / parent Apple ID → Safari step: tap Open Settings, toggle the Prime Kids extension on, return → Finish. Dashboard rows show Active.
3. **Parent picks apps on the child device (15 s)** — ⚙ → Parent settings → create PIN → Manage apps & categories → pick 2–3 apps → Done → "Selected: N apps".
4. **Enforcement (20 s)** — in the parent app: App Rules → Block selected apps ON → back on the child phone open a picked app → **Prime Kids shield** appears. Tap "Ask parent", then Close.
5. **Remote pause (15 s)** — parent app: Devices → Pause → child phone: open any app → shield "Device paused"; Resume → app opens again.
6. **Location + SOS (15 s)** — parent app: child's location on the map; child phone: hold SOS → parent receives the alert.
7. **Unpair (5 s)** — parent app: Devices → Unpair → child returns to the pairing screen.

## Narration (optional, English)
"Prime Kids: Child is installed by the parent on the child's iPhone and paired with the parent's account. During setup the parent authorises Screen Time. The parent chooses which apps are managed on the child's device; rules, schedules and pause come from the parent app and are enforced with Apple's Screen Time shield. Location is shared with the parent for safe-zone alerts and the SOS button."
